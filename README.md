Coin Clash: Spot the Fake! is an interactive Python Tkinter-based game where the player must identify a fake coin among a set of identical-looking coins within limited attempts. One randomly selected coin is either heavier or lighter than the others, and the player can click coins to guess the fake one. The game also demonstrates a binary search-based algorithm that efficiently locates the fake coin by simulating weight comparisons. It includes a graphical user interface, attempt tracking, solution reveal option, and a toggle to display actual coin weights for learning purposes. This project helps understand algorithm design, problem-solving, and GUI development in Python in an engaging and visual way.
